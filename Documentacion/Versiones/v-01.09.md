## Cambios registrados

### 2026-05-20 - Revision threat model e import/export soft-delete

- El threat model recibido se reviso como checklist de seguridad; venia duplicado y no era una lista atomica de bugs.
- Hallazgo corregido: importacion y exportacion podian operar sobre cuentas activas cuyo titular estaba soft-deleted si se llamaba con `cuentaId` directo.
- `ImportacionService`, exportacion manual y exportacion mensual exigen ahora titular activo.
- `ActualizacionService` corta descargas de paquetes durante streaming si superan el limite; `UpdateSecurity:MaxUpdatePackageBytes` permite bajarlo por instalacion sin superar el maximo productivo de 300 MB.
- Verificacion: `ImportacionServiceTests|ExportacionServiceTests|ActualizacionServiceTests` 63/63 OK con SDK local.
- Pendiente de release: Docker/Testcontainers y E2E autenticado real.

### 2026-05-20 - Correccion fuga de diagnosticos internos IA

- Confirmado y corregido el hallazgo `AI provider network errors leak internal diagnostics`.
- Los errores de red de OpenRouter/OpenAI ya no devuelven `Detalle tecnico` ni mensajes crudos de transporte al usuario.
- La auditoria IA conserva solo codigos seguros de transporte (`tls_certificate`, `proxy_unavailable`, `dns_resolution_failed`, `connection_refused`, `network_error`).
- `Directory.Build.props` excluye `.local-build`/`.codex-build` de MSBuild y `.gitignore` ignora `.local-build` anidados.
- Verificacion: regresion focalizada 1/1 OK, `AtlasAiServiceTests` 62/62 OK y `git diff --check` OK.
- Pendiente de release: suite completa, Docker/Testcontainers y E2E autenticado real.

### 2026-05-20 - Cierre bypass MFA en refresh token

- `REFRESH_TOKENS` incluye `mfa_verified_at` para distinguir sesiones que completaron MFA de sesiones legacy/pre-MFA.
- `RefreshTokenAsync` revoca y rechaza con `401` los refresh tokens sin garantia MFA cuando `RequireMfaForWebUsers` esta activo.
- La rotacion conserva `mfa_verified_at`, por lo que el refresh legitimo tras MFA sigue funcionando aunque el usuario no marque `Recordar dispositivo`.
- Verificacion: reproduccion previa fallida del exploit, `AuthServiceTests` 18/18 OK y suite backend sin Docker/Testcontainers 261/261 OK.
- Pendiente de release: ejecutar Testcontainers y E2E autenticado real.

### 2026-05-20 - Hardening de login contra DoS por IP compartida

- Confirmado y corregido el hallazgo `Per-client login throttle enables unauthenticated DoS`.
- El contador cliente/IP ya no bloquea credenciales validas antes de verificar password.
- Los intentos invalidos siguen limitados por email+cliente y cliente/IP.
- Un login correcto limpia tambien el contador cliente/IP.
- `ForwardedHeaders` queda activado con `KnownProxies`/`KnownNetworks` configurables para despliegues con proxy inverso.
- Regresiones agregadas en `AuthServiceTests`: DoS de IP compartida y limpieza de contador post-login.
- Verificacion: `AuthServiceTests` 20/20 OK con SDK local; suite backend sin Docker/Testcontainers 267/267 OK; `git diff --check` OK en archivos tocados.
- Pendiente general: suite completa, Docker/Testcontainers y E2E autenticado antes de release final.

### 2026-05-20 - Logout limpia MFA recordado

- `POST /api/auth/logout` vuelve a borrar `mfa_trusted`.
- El dispositivo MFA recordado baja de 90 a 62 dias.
- El administrador decide si se permite recordar dispositivos mediante `mfa_remember_device_enabled`; por defecto queda apagado.
- Si la politica esta apagada, el backend ignora `mfa_trusted`, exige TOTP y limpia la cookie.
- Tests focalizados de logout y MFA recordado pasan.
- El fallo independiente `RefreshToken_Should_Reject_PreMfa_Token_When_Mfa_Becomes_Required` queda cerrado por el bloque de bypass MFA de esta misma version.

### 2026-05-20 - Fix de compatibilidad ZIP en actualizador

- `ActualizacionService.TryExtractPackageSafely` acepta entradas raiz inocuas (`.` / `./`) sin aflojar Zip Slip.
- Regresiones anadidas:
  - Paquete firmado con entrada raiz `.`.
  - Paquete firmado con entrada raiz `./`.
  - Paquete firmado con `../evil.txt`, que debe rechazarse sin llamar al Watchdog.
- Verificacion:
  - Reproduccion previa: `ActualizacionServiceTests` fallaba con `rootDirectoryEntry: "."`.
  - Tras el fix: `ActualizacionServiceTests` 13/13 OK.
  - Bloque actualizacion/watchdog 20/20 OK.
- Pendiente no relacionado en ese momento: suite backend sin Docker/Testcontainers quedaba en 256/258 por fallos ajenos de IA/Auth; el fallo Auth queda cerrado por el bloque de bypass MFA.
