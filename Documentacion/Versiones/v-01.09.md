### 2026-05-20 - Cierre bypass MFA en refresh token

- `REFRESH_TOKENS` incluye `mfa_verified_at` para distinguir sesiones que completaron MFA de sesiones legacy/pre-MFA.
- `RefreshTokenAsync` revoca y rechaza con `401` los refresh tokens sin garantia MFA cuando `RequireMfaForWebUsers` esta activo.
- La rotacion conserva `mfa_verified_at`, por lo que el refresh legitimo tras MFA sigue funcionando aunque el usuario no marque `Recordar dispositivo`.
- Verificacion: reproduccion previa fallida del exploit, `AuthServiceTests` 18/18 OK y suite backend sin Docker/Testcontainers 261/261 OK.
- Pendiente de release: ejecutar Testcontainers y E2E autenticado real.

### 2026-05-20 - Hardening de login contra DoS por IP compartida

- Confirmado y corregido el hallazgo `Per-client login throttle enables unauthenticated DoS`.
- El contador cliente/IP ya no bloquea credenciales validas antes de verificar password.
- Los intentos invalidos siguen limitados por email+cliente y cliente/IP.

- `ForwardedHeaders` queda activado con `KnownProxies`/`KnownNetworks` configurables para despliegues con proxy inverso.
- Regresiones agregadas en `AuthServiceTests`: DoS de IP compartida y limpieza de contador post-login.
- Verificacion: `AuthServiceTests` 20/20 OK con SDK local; suite backend sin Docker/Testcontainers 267/267 OK; `git diff --check` OK en archivos tocados.
- Pendiente general: suite completa, Docker/Testcontainers y E2E autenticado antes de release final.

### 2026-05-20 - Logout limpia MFA recordado

- `POST /api/auth/logout` vuelve a borrar `mfa_trusted`.
- El dispositivo MFA recordado baja de 90 a 62 dias.
- El administrador decide si se permite recordar dispositivos mediante `mfa_remember_device_enabled`; por defecto queda apagado.
- Si la politica esta apagada, el backend ignora `mfa_trusted`, exige TOTP y limpia la cookie.
- Tests focalizados Auth/Configuracion: 29/29 OK; frontend lint/build OK.
- Pendiente de empaquetado: la sincronizacion local de `wwwroot` quedo bloqueada por `Access denied`; regenerar assets con permisos antes de publicar release.
- El fallo independiente `RefreshToken_Should_Reject_PreMfa_Token_When_Mfa_Becomes_Required` queda cerrado por el bloque de bypass MFA de esta misma version.
