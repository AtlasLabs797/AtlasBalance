### 2026-06-08 - Actualizador, MFA recordado, OpenRouter y paises

- Actualizador GitHub: `GET /api/sistema/version-disponible` informa `instalable`, `bloqueos`, ZIP detectado, firma, digest, clave publica y disponibilidad real de Watchdog. `Actualizar ahora` queda bloqueado si hay update pero no es instalable.

- Render IA: el frontend renderiza texto/Markdown seguro con listas, tablas, bloques de codigo y JSON simple sin HTML crudo.
- Paises: nueva tabla `PAISES`, CRUD `/api/paises`, `CUENTAS.pais_id` nullable, filtros por pais en cuentas/dashboard y agregado `saldos_por_pais`.
- Frontend: selectores de pais en cuentas y dashboard, entrada libre con sugerencias para modelos OpenRouter, preflight visible de actualizacion y boton de update condicionado a `instalable`.
- Tests agregados/actualizados para preflight de updater, MFA recordado/revocado/90 dias, modelos OpenRouter arbitrarios y dashboard por pais.
- Verificacion: frontend `npm run build` OK; backend build OK con SDK `8.0.419`; tests focalizados backend 122/122 OK; `git diff --check` OK con avisos CRLF.
